# Bank Loan Data Analysis

## Project Overview
This project focuses on analyzing bank loan data to gain insights into loan applications, funded amounts, received payments, regional performance, loan purposes, and customer profiles.  

The analysis was performed using Python libraries such as Pandas, NumPy, Matplotlib, and Plotly for data cleaning, analysis, and visualization.

---

## Objectives
- Analyze total loan applications
- Track funded and received loan amounts
- Identify regional loan distribution
- Understand loan purposes and customer behavior
- Visualize trends using interactive charts

---

# Key Performance Indicators (KPIs)

## Loan Applications Analysis
- Total Loan Applications

## Funded Amount Analysis
- Total Funded Amount

## Received Amount Analysis

- Monthly Received Amount Trends

## Loan Performance Analysis
- Good Loan Percentage
- Bad Loan Percentage
